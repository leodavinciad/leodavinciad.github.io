# Capability Radar Setup Checklist

## Needed from Enrico before newsletter launch

Choose one:

- **Buttondown** — recommended for developer-facing publication
- **Substack** — easiest if built-in newsletter discovery matters more
- **Beehiiv** — useful later if growth/ads become important

Needed details:

- publication name: `Capability Radar`
- sender/from name: `Capability Radar` or `Leonardo Research Labs`
- reply-to email address

### 2. Public contact email

Choose one:

- create a dedicated email such as `capabilityradar@...`

Needed details:

- desired email address
- whether Leonardo can use it for inbound suggestions

### 3. Domain decision — optional

Current default:

- `https://leodavinciad.github.io/capability-radar/`

Optional later:

- `capabilityradar.ai`
- `capabilityradar.dev`
- `capabilityradar.com`

Needed only if Enrico wants a separate brand domain:

- domain registrar access or approval to buy/register
- DNS access for GitHub Pages/newsletter verification

### 4. Social publishing accounts

For public launch posts, Leonardo needs one of:

- Enrico posts manually from his own X/LinkedIn using the launch kit, or
- a dedicated **Capability Radar** X/LinkedIn account is created, or
- Leonardo receives API/automation access later

Recommended MVP:

- Leonardo prepares and iterates copy
- no automated social posting yet

Needed details if creating separate accounts:

- X/Twitter handle preference
- LinkedIn page decision

- posting policy: draft-only or approved autonomous posting

2. manual `premium` reply CTA
3. Lemon Squeezy or Gumroad after 3+ people express paid interest

Needed when ready:

Optional:

Needed if enabled:

- site ID/script
- consent/privacy preference
