# Capability Radar

**The weekly capability brief for AI agent builders.**

Capability Radar tracks MCP servers, Agent Skills / `SKILL.md` packages, registries, payment protocols, and agent marketplaces — then tells builders what to **test**, **skip**, and **watch**.

> Spend 10 minutes a week deciding which new agent capabilities are worth your time.

## Who it is for

- Developers building AI agents
- MCP/server/tooling maintainers
- AI automation builders
- Technical founders exploring agent products
- Power users running Claude Code, Codex, OpenCode, Hermes, Cursor, MCP tools, and custom agents

## Why it exists

Agent builders have a trusted capability discovery problem. The ecosystem now has thousands of MCP servers, tool registries, skills, marketplaces, and payment protocols. Some are useful. Some are duplicates. Some are demos. Some are unsafe or poorly maintained.

Capability Radar is not generic AI news. Each issue gives an operator verdict:

- **Test** — useful enough to try now
- **Skip** — not worth attention yet
- **Watch** — early signal that could matter soon
- **Useful, not production-ready** — good direction, immature implementation
- **Good idea, weak execution** — concept matters, current artifact does not

## Weekly format

Each issue includes:

1. **Top recommendation** — the one capability worth testing now
2. **Test** — 3 tools/protocols/skills with practical use cases
3. **Skip** — 3 items that look interesting but are not worth time yet
4. **Watch** — 3 early signals that may matter soon
5. **Builder experiment** — one low-friction test readers can run this week
6. **Radar queue** — what will be evaluated next

## Evaluation criteria

Every candidate is scored on:

- Builder usefulness
- Installation friction
- Documentation quality
- Maintenance signal
- Security / credential risk
- Workflow fit
- Novelty versus duplication
- Production readiness
